STIG in Splunk — operator guide

Offline reference shipped with the app. Open the SplunkUI Documentation view for in-app links.

1. Overview

STIG in Splunk stores DISA STIG baseline and checklist review state in KV store. Import baselines, register hosts per workspace, assign STIGs, review in the editor, and report from dashboards or export. Not a STIG Manager fork.

2. Before you begin

  • Splunk Enterprise 9.x with KV store.
  • Indexes stig and stig_audit (app defaults).
  • Splunk admin for roles and HEC.

3. Install

Install tarball via Manage Apps or extract to $SPLUNK_HOME/etc/apps/stigs_in_splunk.

chown -R splunk:splunk $SPLUNK_HOME/etc/apps/stigs_in_splunk

The installable app does not ship metadata/local.meta (instance permissions belong in runtime local/ on the Splunk box). Splunk creates or updates that file when you save object permissions; ensure local/ and metadata/ are owned by the splunk user after install. For bind-mount dev, ./scripts/link-splunk-app.sh seeds an empty metadata/local.meta so UCC settings can save.

Production installs use the tarball; developer builds use ./scripts/build_ucc.sh.

4. Access control

CapabilityMeaning
stig_readView STIG data via app REST.
stig_writeCreate and update STIG data.
stig_review_acceptAccept or reject submitted reviews.
stig_adminManage workspace ACLs and deletes.

Assign roles stig_user or stig_admin under Splunk Settings → Roles.

5. HTTP Event Collector (HEC)

  • Input: stig_findings
  • Index: stig
  • Sourcetype: stig:finding

Configure the token in Splunk Settings → Data inputs → HTTP Event Collector. The app does not store the token.

6. Quick start (about 15 minutes)

  1. Workspaces — Create a workspace or use Default (auto-created). Default import target can be changed in Workspaces.
  2. Import baselines — Import → Baselines tab (global catalog).
  3. Hosts — Register hosts in your workspace.
  4. Assign STIG — Editor: select workspace and host, then Assign STIG (or STIG library).
  5. Review findings — Editor → Write (Submit when required).
  6. Collection dashboard — Review metrics and POA&M after findings exist.

7. Import reference

Baselines — XCCDF/CKL/zip catalog (no workspace). Checklists — workspace-scoped CKL/CKLB/zip. Automation: REST /stig_imports, HEC stig:finding, reconcile every 5 minutes. See repo docs/automation.md.

8. Multi-user governance

Configure Workspace grants (owner/manager/member/restricted). Members need stig_write. Accept/Reject requires stig_review_accept or owner/manager grant.

9. Troubleshooting

  • Blank Workspaces page — install built tarball; run ./scripts/build_ucc.sh for git dev trees.
  • 403 / empty UI — assign stig_user and edit_kvstore.
  • Empty editor — import baselines, assign STIG to selected host.
  • UCC save errors — fix chown on app directory.
  • Delete workspace 409 — remove dependents or REST cascade delete.
  • Search empty after import — verify HEC token on stig_findings.
